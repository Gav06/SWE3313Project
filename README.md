The provided jar file or the Piero's Pizza Point-of-sale system is executable. 
It is recommended you execute it via the command line to ensure it works as the jar file itself produces no GUI. 

Run command: java -jar PierosPizzaPOS.jar

Please make sure your java installation is Java 17 or higher.
You can check with command: java -version

Once you execute the jar file and launch the application, go into your web browser and enter localhost:8080 in the address bar to use the application interface.
